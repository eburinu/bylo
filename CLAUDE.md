## Что это
«Антиплагиат для идей, которых ещё нет». По брифу (задание хакатона, гранта, тема
курсовой) генерируем N «соседей» — независимых LLM-сессий с разными моделями и
персонами, — собираем их идеи, кластеризуем и для идеи пользователя показываем:
сколько соседей пришли к ней же, ближайшие клоны, совпадение названия и поворот,
который выводит идею из кластера.

Делается на хакатоне «Вайбкодинг ФКН», тема 4 «Open Source × AI». Репозиторий пока
приватный, потом откроем — **никаких секретов в истории**.

## Контракт
Формат идеи, файлов и ответов API — в `docs/SCHEMA.md`. Это граница между частями:
поменял — предупреди остальных и поправь seed/моки.

### Для `web/` — что уже отдаёт API (engine, 25.10)
- `GET /api/map` и `POST /api/check` работают на seed без ключа и без сети:
  `uvicorn engine.api:app --reload`, затем `http://127.0.0.1:8000/api/map`.
  Пока нет `data/pool/fkn2026.json`, отдаётся seed (8 соседей) — потом станет 100.
- `cluster` в ответе `/api/check` может быть `null` (ни один сосед не выше порога).
- **Клон = `c.match`** (с 14:30): решает судья-LLM, а не косинус — эмбеддинги путают
  слова с механикой (см. `pairs.csv`). В `web/index.html` замените
  `c.similarity >= r.threshold` на `c.match` (строки ~272 и ~309). Признанные клоны
  идут в `clones` первыми, дальше просто ближайшие.
- `judged: false` — сети не было, `match` посчитан по порогу косинуса `threshold`.
- `similarity` — косинус после центрирования (~0 не связаны). Для полоски годится,
  как проценты не рисуйте.
- `{"twists": false}` в запросе — быстрый ответ без поворота (поворот +5–10 с).
- Первый `/api/map` после запуска ~20 с (эмбеддинги, t-SNE), дальше из кэша.
- Положите `web/index.html` — API сам раздаст страницу на `/`, CORS открыт.

## ИНВАРИАНТЫ — НЕ ЛОМАТЬ

1. **Коллизия = доля симуляций**, где нашлась та же идея, а не доля идей.
   Говорим «придумали бы 9 команд из 100».
2. **Сравниваем по `mechanic`**, не по `title`/`pitch`. Название сравнивается отдельно
   (совпадение названий — свой показатель).
3. **Порог «та же идея» — по человеческой разметке** `data/gold/pairs.csv`, не на глаз.
4. **Поворот оригинален только после перепроверки** по пулу (лучше — новой выборкой).
   Без этого генератор «оригинального» сам выдаёт идею из кластера — проверено.
5. **Демо не зависит от сети.** Пул, эмбеддинги и ответы для заготовленных идей
   лежат в `data/cache/`; `/api/check` сначала смотрит кэш.
6. **Ключи — только в `.env`** (он в `.gitignore`). Перед коммитом смотри
   `git diff --cached`: репозиторий станет публичным, история тоже.
7. **LLM — через OpenAI-совместимый клиент** с `LLM_BASE_URL` из env (OpenRouter,
   DeepSeek и т.п.). Модели — из env, не хардкодить.

## Данные на старте
`data/seed/sims_2026-10-25.json` — 68 идей от 8 «соседей», прогнанных утром
(чистые агенты Claude: Opus, Sonnet, Haiku; разные формулировки брифа).
Поле `manual_cluster` — ручная разметка: годится как эталон для проверки
кластеризации (ARI), но не как истина. На seed можно строить всё до того, как
заработает генератор.

## Запуск
Заполняем по мере готовности:
```
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
uvicorn engine.api:app --reload      # web/index.html раздаётся на /
python -m engine.llm                 # проверка ключа: каждая модель вернула JSON
python -m engine.embed_cluster       # ARI на seed без сети
python -m engine.generate --n 20     # дописать пул data/pool/fkn2026.json
```
Torch 2.14 + sentence-transformers 6.2 ставятся на Python 3.14 (CPU).
Пока нет `data/pool/fkn2026.json`, API отдаёт seed.
