# Было

Антиплагиат для идей, которых ещё нет.

Даёшь задание (хакатон, грант, тема курсовой) и свою идею — «Было» запускает сотню
независимых ИИ-«соседей» с тем же заданием и показывает, сколько из них пришли к той же
идее, кто ближайшие клоны, совпало ли название и какой поворот выводит идею из толпы.

Зачем: генеративный ИИ делает каждого креативнее, а всех вместе — одинаковее
([Doshi & Hauser, Science Advances 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11244532)).

## Как пользоваться
Открываешь страницу, пишешь идею в паре предложений («что на входе → что делает → что на
выходе») и жмёшь «Проверить». Через ~15 секунд:
- **вердикт** — сколько команд из 100 придумали бы то же самое;
- **клоны** — идеи соседей с той же механикой (и какая модель их придумала);
- **совпадение названия**;
- **поворот** — 2–3 варианта, как изменить механику, каждый перепроверен по пулу;
- **карта** — все идеи соседей, кластеры самых частых.

## Запуск
```
python -m venv .venv && .venv\Scripts\activate     # Windows
pip install -r requirements.txt
cp .env.example .env                                # вписать ключ OpenRouter и модели
uvicorn engine.api:app                              # → http://localhost:8000
```
Пул для нашего хакатона (`data/pool/fkn2026.json`) и ответы для демо-идей уже лежат в
репозитории — карта и примеры работают без ключа и без сети.

**Свой бриф** (грант, курсовая, другой хакатон):
```
# 1. текст задания → data/briefs/<имя>.md
python -m engine.generate --brief <имя> --n 100     # ~100 соседей, ~$2 на OpenRouter
# 2. открыть страницу с ?brief=<имя> или POST /api/check {"brief": "<имя>", "idea": "..."}
```

## Результаты
Соседи с заданием реального хакатона Devpost заранее «придумали» **34%** и **20%** его
проектов (212 и 744 проекта); соседи с чужим заданием — 3–4%. На «Вайбкодинг ФКН» самую
частую идею придумали 37 соседей из 98. Подробно — [docs/RESULTS.md](docs/RESULTS.md).

## Устройство
1. Бриф → N соседей: разные модели, персоны и формулировки.
2. Каждая идея сжимается в одну строку механики.
3. Эмбеддинги → кластеры → карта.
4. Идея пользователя → доля соседей с той же идеей, клоны, поворот с перепроверкой.
