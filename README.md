# Было

Антиплагиат для идей, которых ещё нет.

Даёшь задание (хакатон, грант, тема курсовой) и свою идею — «Было» запускает сотню
независимых ИИ-«соседей» с тем же заданием и показывает, сколько из них пришли к той же
идее, кто ближайшие клоны, совпало ли название и какой поворот выводит идею из толпы.

Зачем: генеративный ИИ делает каждого креативнее, а всех вместе — одинаковее
([Doshi & Hauser, Science Advances 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11244532)).

> Статус: делаем на хакатоне «Вайбкодинг ФКН». Инструкция по запуску появится по ходу.

## Устройство
1. Бриф → N соседей: разные модели, персоны и формулировки.
2. Каждая идея сжимается в одну строку механики.
3. Эмбеддинги → кластеры → карта.
4. Идея пользователя → доля соседей с той же идеей, клоны, поворот с перепроверкой.
